# Input

Text field with label, hint and error, on `surface-1` with an 8px radius.

- Border `hairline-strong`; focus = `primary-focus` border plus a 2px ring at 50% opacity.
- Error: border and message in `danger` (an addition, not in the source). Always write the error in words.
- 16px text, min height 44px for touch. The consumer provides `label`, `placeholder` and validation.
