# Amount

Money value in USD ($) or KHR (៛) with tabular figures, coloured by direction.

- Mono face with tabular numbers so columns line up; `size="lg"` uses display-md for the balance.
- `signed` shows + / − : income in `success`, expense in `danger`. Unsigned values stay `ink`.
- The sign is always shown in text, so colour is never the only signal. The consumer converts currencies; this only formats.
